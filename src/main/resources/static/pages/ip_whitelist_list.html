白名单模式（推荐）

                                    
只允许列表中的 IP 访问，未命中则默认拒绝

                                

                                

                                    
                                    
黑名单模式

                                    
拒绝列表中的 IP 访问，其他 IP 默认允许

    • 
                                    
  • 172.16.0.0/16 - CIDR 网段（172.16.x.x）
    • 
                                    
  • 192.168.1.1-192.168.1.255 - IP 段范围
    • 
                                    
  • localhost - 本地回环地址
